# 로그라인 카드 (① 로그라인 공방)

근거: screenwriting `sw-premise-theme` 6절(스나이더 한 줄 이야기, 혹스터 로그라인)·10절(희핵), `sw-industry-business`(PROBLEM 아이디어 점검), 시리즈는 `sw-series-engine-bible` 8·10·16항.

## 1. 카드

```
북극성 로그라인: {한두 문장}
- 주인공(형용사 + 결함):
- 촉발 사건:
- 욕망·목표(겉) / 필요(속):
- 맞서는 힘(적대자 형용사):
- 걸린 것(잃으면 무엇을 잃나):
- 갈고리·아이러니:
- 장르 약속:
- 통제 아이디어(가치 + 원인): "…은 …때문에 이루어진다/무너진다"
- 희핵: 이것을 빼면 극이 무너지는 한 가지
- (시리즈) 엔진: 매주 이야기가 생기는 이유 한 줄 / 시즌 질문
- (실화) 실제와 각색의 경계:
```

## 2. 만드는 법

1. 씨앗(장면·인물·질문 하나)에서 후보 5개를 쓴다. 서로 장르나 주인공 결함이 달라야 한다.
2. 아래 테스트를 후보마다 돌려 표로 보여 주고, 작가가 하나를 고른다. 섞어서 새 후보를 만들어도 된다.
3. 고른 것을 story-bible 맨 위 "북극성" 칸에 적는다. 이후 단계는 모두 이 칸과 대조한다.

## 3. 테스트

| 테스트 | 통과 조건 |
|-|-|
| 낯선 사람 테스트 | 처음 듣는 사람에게 한 번에 말해도 눈길이 떠나지 않는다(subagent에게 로그라인만 주고 "무슨 이야기인지, 보고 싶은지" 묻기) |
| 아이러니 | 주인공과 상황 사이에 어긋남이 있다 |
| 머릿속 그림 | 듣자마자 장면이 떠오르고 시간 범위가 보인다 |
| 대립 | 맞서는 힘이 주인공보다 세다 |
| 걸린 것 | 실패하면 구체적으로 잃는 것이 있다 |
| 희핵 | 그 한 가지를 빼면 이야기가 무너진다(빼도 되면 곁가지) |
| "X가 Y를 만나다" 금지 | 상황 나열이 아니라 갈등과 선택이 있다 |
| PROBLEM 점검 | sw-industry-business의 7요소 점검표를 통과한다 |
| (시리즈) 회차 확장 | 파일럿 다음 3회를 바로 말할 수 있다. 무한 연장형이면 100회 질문, 한정 시리즈면 엔진이 힘을 잃는 회차 |
| (공공·실화) 동의 가능성 | 실제 인물이 읽어도 동의할 수 있는 선 안에 있다 |

## 4. 로그라인 대조 (②~⑥ 단계 끝마다)

한 줄 형식: `{단계} 대조: {이 단계의 결과}가 {로그라인의 어느 요소}를 {키우는가/흐리는가} → 예/아니오(이유)`.
"아니오"가 두 단계 이상에서 나오면 ⑦에서 ①로 되돌린다.
